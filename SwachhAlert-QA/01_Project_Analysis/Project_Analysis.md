# SwachhAlert - Project Analysis

## 1. Project Overview

Project Name:
SwachhAlert

Application Type:
Urban Waste Management Web Application

Purpose:
SwachhAlert allows residents to report garbage-related issues with location and image evidence while enabling municipal administrators to manage and resolve complaints through an admin dashboard.

## 3. User Roles

Resident

Permissions

- Register
- Login
- Submit Complaint
- View Own Complaints
- View Complaint Details

Restrictions

- Cannot view all complaints
- Cannot update complaint status

----------------------------------

Admin

Permissions

- Login
- View All Complaints
- Update Complaint Status

Restrictions

- Cannot access resident-only data unless permitted by business rules
